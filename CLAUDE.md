# ai-tools

Treat this repo as **public**, always. Visibility is currently private only as a staging convenience — assume every file, commit message, and comment will be read by strangers.

## Rules

- No secrets, tokens, or `.env` contents — not in code, not in examples, not in test fixtures.
- No absolute home paths. Use relative paths or environment variables (`$HOME`, `${CONFIG_DIR}`).
- No content copied from a private assistant/config tree, personal notes, or internal work systems.
- No employer names, internal hostnames, ticket numbers, or coworker names.
- Example data is synthetic. Never paste a real log, request, or record.
- Repo visibility is changed by hand, in the GitHub UI, by the owner only.
